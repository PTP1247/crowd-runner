# Crowd Runner (Python midterm)

เกมคนวิ่งผ่านประตู `+ - × ÷` เลียนแบบเกมโฆษณา ทำด้วย Pygame

## รันเกม

```bash
python -m venv .venv
# Windows:      .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## ปุ่ม

| ปุ่ม | ทำอะไร |
|---|---|
| ขึ้น/ลง (W/S) + Space หรือ Enter | เลือกด่านแล้วเริ่มเล่น |
| A, D หรือ ลูกศรซ้าย/ขวา | เลื่อนกลุ่มคน |
| P หรือ Esc | หยุดเกมชั่วคราว (กดปุ่มไหนก็ได้เพื่อเล่นต่อ ยกเว้น R / M / N) |
| R | เริ่มด่านนี้ใหม่ (ระหว่างเล่น, ตอนหยุด, หน้าจบ) |
| Enter | หน้าจบ: ชนะ = ไปด่านถัดไป, แพ้ = เล่นใหม่ |
| M | กลับเมนูเลือกด่าน (ตอนหยุด, หน้าจบ) |
| N | เปิด/ปิดเสียง |
| U | ปลดล็อกทุกด่านชั่วคราว ไว้ทดสอบ/โชว์ (ในเมนู กดอีกครั้งเพื่อปิด, ไม่บันทึก) |

## ในเกมมีอะไรบ้าง

- **ประตู** `+ - × ÷` เลขสุ่มใหม่ทุกรอบ และบางคู่สลับซ้าย/ขวา แต่ความยากของด่านเท่าเดิม
- **สิ่งกีดขวาง** กล่องลายเหลือง-ดำ คนที่ทับหายหมด ความกว้าง/การแกว่งสุ่มทุกรอบ โหดขึ้นตามความยากของด่าน แต่เช็กแล้วว่าหลบทันเสมอ
- **ศัตรู** (คนสีแดง) ปะทะกันทีละคนราว 1 วินาที ระหว่างนั้นหยุดวิ่ง
- **เสียง** สังเคราะห์ในโค้ด (`sound.py`) ไม่ใช้ไฟล์เสียง
- ด่านแรกมีคำแนะนำการเล่น 5 วินาทีแรก, หน้าจบบอกว่าแพ้เพราะอะไร และต้องเหลือกี่คนถึงได้ดาวถัดไป

## ทดสอบ

```bash
python -m pytest        # หรือ python tests/test_logic.py
```

## ด่านและคะแนน

- ด่านอยู่ใน `levels/level1.json` ถึง `level10.json` เพิ่มไฟล์ใหม่แล้วจะขึ้นในเมนูเอง (เรียงตามเลข)
- ดาว: ชนะ = 1 ดาว, เหลือคน >= 25% ของจำนวนสูงสุดที่เป็นไปได้ = 2 ดาว, >= 50% = 3 ดาว
- high score บันทึกใน `highscores.json` (แต่ละเครื่องแยกกัน ไม่เข้า git)
- กติกาด่าน (test ตรวจให้): เลือกประตูดีที่สุดแล้วต้องชนะได้ และสิ่งกีดขวางที่สุ่มได้ต้องหลบทัน
- เมนูมีขีดความยาก 1-4 ขีดหน้าชื่อด่าน มาจาก `level.difficulty()`

### ความยากของด่าน

`level.difficulty(level)` ให้คะแนน 0-100 = ประตูที่เลือกผิดครั้งเดียวก็แพ้ (40) + เลือกผิดได้กี่ครั้ง (25) + ความเร็ว (15) + จำนวนสิ่งกีดขวาง (20)
test บังคับว่าแต่ละด่านต้องไม่ง่ายกว่าด่านที่ยากที่สุดก่อนหน้าเกิน 5 คะแนน

### แก้/เพิ่มด่าน (`levels/*.json`)

| type | field | หมายเหตุ |
|---|---|---|
| `gate_pair` | `z`, `left`, `right` เช่น `["x", 2]` | เลขสุ่มใหม่ตอนเล่น แต่ชนิด `+ - x /` คงเดิม |
| `obstacle` | `z` (+ `x`, `width`, `damage`) | ตอนเล่นใช้แค่ `z` ที่เหลือสุ่มใหม่ (`damage` ไม่ได้ใช้) |
| `enemy` | `z`, `count` | |

แก้ด่านแล้วรัน `python -m pytest` ทุกครั้ง ด่าน 2 และ 6 ไวต่อตัวเลขมาก (ดูข้อความ test ที่ fail ว่าด่านไหนง่าย/ยากผิดลำดับ)
