# Crowd Runner (Python midterm)

เกมคนวิ่งผ่านประตู `+ - × ÷` เลียนแบบเกมโฆษณา ทำด้วย Pygame

## รันเกม

```bash
python -m venv .venv
# Windows:      .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## ปุ่ม

| ปุ่ม | ทำอะไร |
|---|---|
| ขึ้น/ลง (W/S) + Space หรือ คลิก | เลือกด่านแล้วเริ่มเล่น |
| A, D หรือ ลูกศรซ้าย/ขวา | เลื่อนกลุ่มคน |
| กดเมาส์ค้างแล้วลาก | เลื่อนกลุ่มคนตามเมาส์ |
| V | สลับมุมมอง flat (มองจากบน) / depth (แนวลึก) |
| R | เล่นด่านเดิมอีกครั้ง (หน้าจบ) |
| M | กลับเมนูเลือกด่าน (หน้าจบ) |

## ทดสอบ

```bash
python -m pytest        # หรือ python tests/test_logic.py
```

## ด่านและคะแนน

- ด่านอยู่ใน `levels/level1.json` ถึง `level10.json` เพิ่มไฟล์ใหม่แล้วจะขึ้นในเมนูเอง (เรียงตามเลข)
- ดาว: ชนะ = 1 ดาว, เหลือคน >= 25% ของจำนวนสูงสุดที่เป็นไปได้ = 2 ดาว, >= 50% = 3 ดาว
- high score บันทึกใน `highscores.json` (แต่ละเครื่องแยกกัน ไม่เข้า git)
- กติกาด่าน (test ตรวจให้): สิ่งกีดขวางกว้างไม่เกิน 150 (ครึ่งถนน) และเลือกประตูดีที่สุดแล้วต้องชนะได้

## โหมดไม่รู้จบ (Endless Mode)

แถวล่างสุดของเมนู เล่นได้เสมอ วิ่งไปเรื่อยๆ จนคนหมด คะแนน = ระยะทาง (บันทึกระยะไกลสุดไว้)

- ถนนสร้างทีละ "ช่วง" ยาว 1000 ทุกช่วงยากขึ้น 1 ระดับ: ประตูเยอะขึ้น (2 -> 3 -> 4 คู่),
  สิ่งกีดขวางเยอะและกว้างขึ้น, วิ่งเร็วขึ้น (300 -> สูงสุด 550)
- **วัดความยากด้วยสัดส่วนเส้นทางที่ชนะ:** ประตู n คู่ = 2^n เส้นทาง ไล่จำนวนคนตามทุกเส้นทาง
  (สมมติว่าหลบสิ่งกีดขวางได้หมด) เส้นทางที่ยังเหลือคนหลังสู้ศัตรู = ชนะ
- ตัวสร้างสุ่มประตูก่อน แล้ว **เลือกขนาดศัตรูท้ายช่วง** ให้สัดส่วนทางชนะใกล้เป้า:
  เริ่ม 75% แล้วคูณ 0.85 ทุกช่วง ต่ำสุด 10% และต้องมีอย่างน้อย 1 ทางที่ชนะเสมอ
- จำนวนคนทุกเส้นทางไม่เกิน 800 (คนเยอะเกินเกมช้า)
- ปรับตัวเลขทั้งหมดได้ที่ต้นไฟล์ `endless.py`
